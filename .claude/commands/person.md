1. Run `node scripts/roster.mjs person NAME --json` (partial name is fine).
2. Present the card top to bottom: paper first (right to work, duty certificate), then the week ahead, then the recent sheets with any variance, then leave and notes.
3. Read the file notes before drafting anything about the person: the notes are the history.
